# 💍 Wedding Invitation Studio

A sophisticated and interactive digital wedding invitation with a real-time RSVP management system. Built with love using modern web technologies.

![Wedding Banner](https://images.unsplash.com/photo-1519741497674-611481863552?auto=format&fit=crop&q=80&w=1200)

## ✨ Features

- 🌸 **Premium Experience**: Elegant design with smooth animations using Framer Motion.
- 🎵 **Romantic Background Music**: Controlled audio playback to enhance the mood.
- ⏳ **Live Countdown**: Dynamic timer counting down to the big day.
- 💌 **RSVP Management**: Advanced form with real-time submission to Supabase.
- 📊 **Guest Dashboard**: A private dashboard to view and search the RSVP list in real-time.
- 📱 **Fully Responsive**: Optimized for every device, from mobile to desktop.
- 📍 **Maps Integration**: Interactive Google Maps for easy navigation to the venue.
- 🚀 **Cloud-Powered**: Real-time database and data synchronization powered by Supabase.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL & Realtime)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Feedback**: [SweetAlert2](https://sweetalert2.github.io/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Deployment**: [GitHub Pages](https://pages.github.com/) + [GitHub Actions](https://github.com/features/actions)

## 🚀 Getting Started

### 1. Installation

```bash
# Clone the repository
git clone https://github.com/Huynguyen030704/wedding-invitation-studio.git

# Navigate to the project folder
cd wedding-invitation-studio/wedding-invitation

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### 2. Supabase Setup

Create a project on [Supabase](https://supabase.com) and run this SQL in the **SQL Editor**:

```sql
create table rsvps (
  id bigint generated by default as identity primary key,
  full_name text not null,
  guest_count text not null,
  guest_of text not null,
  type text default 'Đính Hôn',
  created_at timestamp with time zone default now()
);

-- Enable RLS & Policies
alter table rsvps enable row level security;
create policy "Allow public insert" on rsvps for insert with check (true);
create policy "Allow public select" on rsvps for select using (true);
```

**Important:** Enable **Realtime** for the `rsvps` table in the Supabase Table Editor.

### 3. Environment Variables

Create a `.env` file in the `wedding-invitation/` folder:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Deployment

This project is pre-configured for GitHub Pages.

1. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to **GitHub Repository Secrets**.
2. Push your code to the `main` branch.
3. Enable **GitHub Actions** in the Repository Settings > Pages.
